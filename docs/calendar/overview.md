# Calendar — overview

Publish events to friends. Calendar shows (1) events created by friends and (2) events a friend is attending even if the host is not your friend (**FOAF** via attendance). Anyone with the event on their calendar is an **event watcher** and gets RSVP/comment activity in-app.
